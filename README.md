# 💻 Programación — Java

Repositorio de ejercicios y prácticas de la asignatura de **Programación**, correspondiente al primer curso del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW).

## 📚 Contenido

En este repositorio se recopilan ejercicios realizados durante el aprendizaje de Java, desde los conceptos básicos hasta estructuras de programación más avanzadas.

Los principales contenidos incluyen:

- **Variables y tipos de datos:** declaración, conversión y operaciones.
- **Estructuras condicionales:** `if`, `else` y `switch`.
- **Bucles:** `for`, `while` y `do-while`.
- **Bucles anidados:** creación de figuras geométricas con caracteres.
- **Arrays y cadenas de texto:** manipulación y procesamiento de datos.
- **Números y algoritmos:** operaciones matemáticas y resolución de problemas.
- **Entrada de datos:** uso de `Scanner` para interactuar con el usuario.

## 🛠️ Tecnologías y herramientas

- **Lenguaje:** Java
- **Entorno de desarrollo:** BlueJ
- **Control de versiones:** Git
- **Plataforma de alojamiento:** GitHub

## 📁 Estructura del proyecto

Los ejercicios están organizados en archivos Java independientes, con clases y métodos `main` que permiten ejecutar cada programa por separado.

La estructura puede variar a medida que se añadan nuevas prácticas.

## 🚀 Cómo utilizar el repositorio

Para descargar el proyecto, ejecuta:

```bash
git clone https://github.com/Pablo-Borras/Programacion.git
```

Abre los archivos `.java` desde BlueJ o desde otro entorno compatible con Java y ejecuta el ejercicio que quieras probar.

## 🎯 Objetivo

Este repositorio sirve como registro de mi progreso en programación, permitiéndome practicar los fundamentos de Java, mejorar la lógica de programación y aprender a utilizar Git y GitHub para gestionar mis proyectos.
